SeigoIME APK 자동 빌드
======================

1) GITHUB_APK_GUIDE_KO.md를 먼저 읽으세요.
2) 이 폴더의 내용을 원본 SeigoIME 저장소 main 브랜치에 덮어올리세요.
3) GitHub → Actions → SeigoIME APK 자동 만들기 → Run workflow.
4) 완료 후 Artifacts에서 SeigoIME-APK-숫자를 다운로드하세요.
5) Release APK가 필요하면 2_SET_RELEASE_SIGNING.bat을 실행하세요.
6) 이후부터는 1_GITHUB_APK_BUILD.bat으로 빌드와 다운로드를 한 번에 할 수 있습니다.
